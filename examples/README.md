# Examples — Eberth aortic-banding 0D model

A pulsatile 0D lumped-parameter model of the **Eberth et al. (2009)** transverse
aortic-arch banding experiment in mice (*J. Hypertens.* 27:2010–2021),
implementing the electric-analogy circuit in the lab note *"0d pulsatile"*
(`main.pdf`, Fig. 1 and Eq. 6).

## The two model files

| File | Physiological state | Arch segment | Carotid geometry |
|------|--------------------|--------------|------------------|
| `eberth_aortic_band_prebanding.json` | **Pre-banding** — healthy control, before surgery | **normal arch** (no band) | baseline CCA, both sides |
| `eberth_aortic_band_acute.json` | **Acute** — right after banding, *before* wall remodeling | band (S=53.8) | baseline CCA, both sides |
| `eberth_aortic_band_chronic.json` | **Chronic** — 5–8 weeks post-band, *after* remodeling (what Eberth measured) | band (S=53.8) | Table-1 remodeled (RCCA-B 633/88, LCCA-B 482/42) |

All three are generated by `make_configs.py` from the **same** literature-sourced
physiological parameters. Pre-banding has a normal (unobstructed) aortic arch;
acute and chronic add the **same** calibrated band (`stenosis_coefficient = 53.8`)
and differ only in carotid-wall geometry. The chronic PI targets (3.11 / 1.65)
are matched within ~7%; the pre-banding pulse pressure (~42 mmHg) matches the
paper's baseline CCA.

> **Finding:** pre-banding is symmetric (both carotids PI ≈ 2.07); banding
> immediately splits it (RCCA-B ↑ ≈ 2.85, LCCA-B ↓ ≈ 1.60), and the subsequent
> wall remodeling barely changes it (chronic ≈ 2.88 / 1.53). So the split is set
> by **band position**, present *immediately* on banding — remodeling is the
> response, not the cause, consistent with Eberth's premise.

Full documentation — problem setup, parameter provenance
(FIXED/DERIVED/CALIBRATE), and the calibration — is in
[`eberth_aortic_band_model.md`](./eberth_aortic_band_model.md).

## Physiological question

A stiff band on the aortic arch sits **between** the two carotid takeoffs. The
right carotid (RCCA-B) is **upstream** of the band and stays pulsatile; the left
carotid (LCCA-B) is **downstream** and its pulse is damped by the
resistive–inertial band — at nearly constant mean pressure and flow. The band is
the *only* structural change between the two carotids, so reproducing the
pulsatility asymmetry is the model's key qualitative test.

## Topology

```
heart Qin(t) → aortic valve → ascending aorta (Ra,La,Ca) → node A
   node A ├─→ RCCA-B  → RCR (right head)
          └─→ BAND ΔP_band(Q) → node B
   node B ├─→ LCCA-B  → RCR (left head)
          └─→ descending aorta (Ro,Lo) → RCR (systemic load)
```

## Block mapping (PDF → svZeroDSolver)

| Circuit element (Fig. 1)        | svZeroD block                                             |
|---------------------------------|-----------------------------------------------------------|
| Heart flow source `Qin(t)`      | `FLOW` boundary condition (ejection waveform, one period) |
| Diode aortic valve              | `ValveTanh`                                               |
| Ascending / descending aorta    | `BloodVessel` (`R_poiseuille`, `C`, `L`)                  |
| Band `ΔP_band(Q)` (Young–Tsai)  | `BloodVessel` with `stenosis_coefficient` (+`L`)          |
| Node A / node B                 | `NORMAL_JUNCTION`                                          |
| Terminal beds (Rp–C–Rd)         | `RCR` boundary conditions                                 |

The band uses svZeroD's `BloodVessel` stenosis term, whose governing law
`ΔP = (R + S|Q|)·Q + L·dQ/dt` is exactly the Young–Tsai form in Eq. (6): the
`stenosis_coefficient` **S = Kₜ·ρ/(2A₀²)·(A₀/Aₛ − 1)²** is the Bernoulli/turbulent
term, and `L` is the inertial (`dQ/dt`) term.

## Units

Consistent **mmHg / ml / s**: pressure [mmHg], flow [ml/s], time [s],
so R [mmHg·s/ml], C [ml/mmHg], L [mmHg·s²/ml].

## Run it

```bash
uv run svzerodsolver examples/eberth_aortic_band_chronic.json out.csv
# or the built binary:  ./svzerodsolver examples/eberth_aortic_band_chronic.json out.csv
```

## Reproduce the pipeline

```bash
python examples/make_configs.py                                          # build all three configs (prebanding + acute + chronic)
uv run python examples/calibrate_stenosis.py \
    examples/eberth_aortic_band_chronic.json --write                     # (re)calibrate the band stenosis to the Table-1 PI ratio
uv run python examples/make_figures.py                                   # regenerate the six figures (examples/figures/)
```

Note: `make_configs.py` writes the already-calibrated `stenosis_coefficient =
53.8` into both files, so the calibration step is only needed to re-derive it.

See also `tests/cases/steadyFlow_calibration.json` and the `svZeroDTuner` app
(`applications/svZeroDTuner`) for automated parameter estimation.

## Calibration limits (why 0D can't match both baseline and banded)

The model matches the **banded** carotids and the pulse-pressure redistribution
but over-predicts the **healthy baseline** PI. We tried four independent routes to
fix this (terminal-bed sweep, ejection waveform, a contractile elastance heart,
and combined sweeps) — none matches both, because the band's 0D amplification
(~1.3×) is intrinsically short of the paper's 2.7×; the missing physics is wave
reflection (1D). Full write-up with numbers:
[`calibration_and_limits.md`](./calibration_and_limits.md). The contractile-heart
experiment is reproducible via `make_elastance_config.py`.
